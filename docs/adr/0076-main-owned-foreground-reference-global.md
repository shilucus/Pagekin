# ADR-0076: Main-Owned Foreground Reference Global

Date: 2026-11-13. Status: accepted for the bounded issued foreground reference global/done step after independent current-source/runtime/quality review. Final artifact/Git delivery checks are recorded separately. This is not complete import,imitation or background qualification.

Sources: [F2 sections4.4-4.5](../plans/2026-11-07-creation-runtime-modernization/README.md), [ADR0074](0074-main-owned-foreground-knowledge-driver.md), [ADR0075](0075-main-owned-foreground-reference-style.md), existing `InferGlobalSettingsCommand`, import inference/repair helpers and the global facts/effect/proposal writers.

## Complete Foreground Step

Only issued reference global/done delegates to the closed `import-generation:v1:global` request:run ID,actual execution owner/epoch,original selected model ID or null. Main owns existing generation admission,frozen context and original root/model,durable four-topic query plan,ordered topic formatting,initial inference and at most one syntax repair plus one endpoint correction,global effect prepare/commit/checkpoint,global-to-style transition,heartbeat,terminal handling and actual physical drain. No new ledger,schema,grant,allowance,background permission or author-facing approval is created. Author/unissued consumers and style/blueprints/refresh retain their existing contracts.

The only ACK is automatic opened readiness,identity/sender/token-bound and accepted before any query or LLM dispatch so renderer has bound verified snapshots,diagnostics and reasoning. Global has no style-like precommit whole-config CAS or commit-ready ACK:after complete decoding it reads ready/empty roster revision and commits with that revision. No rejection or alternate approval is inferred from an unsaved config change. Postcommit `publishSavedNovelConfig(...,'unsaved-edits')` retains author buffers and exact session isolation.

Model routing stays at the existing renderer workflow entry:the frozen workflow model or `routeModelId('import-global-facts')`,otherwise null. Main does not introduce another default-model policy. Existing slots use their original model;null may replay their history but cannot start a fresh generation without a selected model (`GENERATION_MODEL_REQUIRED`).

## Materials And Recovery

Reuse `prepareImportQueryMaterials`,fixed worldview/protagonist/conflict/style order and topK5,distinguishing empty from unavailable without downgrading a hard query barrier. Opening/latest samples remain3000 characters with original total chapters/words,templates and planning Skill. Main obtains Skill name/content only from the same source-binding snapshot machinery and compares the rebuilt binding against the original before using it;no renderer content or new persistent Skill field is accepted. Changed bindings fail rather than switching selection. Existing ordinal replay reads its original durable task/receipt.

All actual LLM calls use one original root and generation with sequential import:0/1/2 nonces:initial inference,optional direct-JSON syntax repair only when lexical evidence is preserved,then optional missing-endpoint delta correction. Existing pure parsing/repair helpers and exact task purposes remain authoritative. At most8 cards,one correction and no arbitrary card additions;no-space or invalid delta retains the existing dangling-edge drop contract. Other semantic failures do not become retries. Rejected decoding discards the same completed candidates best-effort;admission or commit failure must not erase valid output required for recovery.

Formal persistence remains `novel-import-global-${runId}`,global/done/global-facts,project-global-facts and the original atomic core/non-character-architecture/operation/proposal/effect/checkpoint transaction. Reference identity-schema results create pending character proposals,never automatically approve/create/merge characters. The actual decoded generation artifacts and purposes remain available to proposal provenance.

Prepared effects recover the original payload,source guard and roster revision without new queries/models. Committed effects use canonical historical receipt readback,not a new domain commit or current-fact revalidation. A committed but still-global step only supplements the missing global-to-style transition under the existing lease;later-stage replay is read-only. Actual completed/completed history returns execution:null without renewing or reconstructing authority. Renderer replay reads current saved core rather than replacing later saved content with historical receipt values.

Whole-step ownership covers opened/query/repair/commit waits,cancel/sender destruction/close/takeover and ignored-abort physical drain. Unknown query or any LLM ordinal never resends under a new owner/epoch/root. Original physical/active-time caps and known hard-error precedence remain. The process-local shared stage flight fences existing same-run legacy writers,including query-materials and direct global commit resolved through its actual generation handle or operation identity;reads,subscriptions and request-cancel remain reachable. A stale owner cannot fail or cancel its successor. Projection failures after commit cannot rewrite durable facts as failed.

## Visible Output And Acceptance

No new layout,copy,asset,control,state or interaction is added. Existing `InferGlobalSettingsCommand` supplies exact bilingual topic counts/fallback,AI/repair/parsing/dropped-edge/save logs;BaseWorkflowCommand supplies Skill,10/90 and prompt-budget projections;global supplies5/20/25/70/90;orchestrator supplies100. The existing verified full-snapshot/reasoning projection remains bound before dispatch. Identity-filtered candidate projection preserves the exact raw candidate before decoding,receipt/context summary and existing fileTree/characterCards refresh remain postcommit only. Noncurrent sessions do not publish into another project.

Trusted bounded-completion messages and their original non-stop finish reason survive the closed response and renderer exception reconstruction. The optional `completionFailureCode` is limited to length/content_filter/cancelled/error/unknown and is emitted only from that explicit local failure type with `GENERATION_REQUEST_FAILED`;malformed metadata or another error-code combination is rejected. Generic failures without that metadata retain the already sanitized main message as a plain error so the workflow log does not replace specific legacy explanations with its generic registered-code copy. Other registered errors retain their codes and existing localization. Structured diagnostics retain their original explicit safe class message,not a different author-input formatter;arbitrary Error messages are never made trusted by this rule.

Acceptance requires actual registered IPC with fictional SQLite/Lance/fetch through complete queries/inference/proposal/effect/transition,exact materials/Skill/root/purpose/ordinal hashes,bounded repairs and rejection,roster CAS/transaction rollback,prepared/committed/completed recovery,unknown no-resend,source/sender/session/lease/writer fences and physical drain. Focused renderer regressions,independent source/runtime review,fresh applicable quality/build and artifact binding precede exact-path local commit. Rollback drains active work and preserves every original receipt/checkpoint/dispatch record;never clear unknown history or issue substitute allowance.
