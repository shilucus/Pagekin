# 章范围反馈使用独立版本，原始范围外字节保持不变

日期：2026-11-07。状态：已接受，仅限本内部薄适配包。Stage 2A/2B 的聚焦运行证据及独立复审见 [Stage 2B 证据](../plans/2026-11-07-creation-runtime-modernization/stage-2b-evidence.md)；不扩大到后续接线或可见设计。

依据：[F2](../plans/2026-11-07-creation-runtime-modernization/README.md) 第 6.1、6.2、7.8 节、FEEDBACK-001 的章范围薄适配验收，以及本轮用户对版本化接口和隔离迁移的实施授权。本决定只扩展 [ADR-0026](0026-planning-feedback-candidates-and-adoption.md) 的内部目标范围；不接受蓝图专用生产接线、可见交互、公共 API 或自动批准合同。

## 决定

- 内部 `plotOutlineRange` 目标是已存在、明确选定的连续章节，沿用现有章节解析器与单次章数上限。缺章、重复、乱序、分组、格式无效或范围超出全书时拒绝；不把整份大纲替换冒充局部修订，不自动补章。
- 新范围使用候选协议 schema 2，冻结 `{kind:'plot-outline-range',from,to}`、原始核心作者事实、`synopsis` 与 `charactersArch`。新增独立单调计数器覆盖这些来源的实际写入及 ABA。八字段 v1 的来源、上下文、任务、hash、采用绑定和已保存行值均不改变。
- F0 是最终采用基线；未采用的 C1 可作为 C2 的真实生成父内容，但不成为新的正式底稿。v2 固定主进程任务包含范围、实际父内容、反馈与约束，并复用现有 planning Skill 来源证明。候选入库与恢复仍核对实际持久化请求、artifact 和完整 stop 收据；unknown 不因此改账或重发。
- 全量采用必须等于整个候选及原冻结范围。部分或手改采用可以指定原范围内的连续子范围，但最终载荷必须恰含所选章节。主进程重新校验最终载荷、原 F0 修订/来源、当前会话与候选，并在同一事务调用 `ProjectCoreRepository.commitSynopsis`、保存采用前值与收据、消费旧 lineage。其余候选及后继不能继续采用剩余章节。
- 反馈替换只改变原选章正文的精确 span，保留前后原始字节、换行、章节分隔及可识别的旧覆盖尾注。旧范围生成 renderer 会重建末尾覆盖说明，因此不能直接用于这条采用路径；新增反馈专用 renderer 复用同一 parser/prefix 校验，原生成逻辑不变。无法与章节正文区分的作者段落仍按现有解析合同属于该章，不猜测新的尾注语义。
- 同内容采用也消费其来源。核心字段同内容采用须同时使依赖这些核心事实的范围基线失效；范围采用不修改未消费的其他字段来源。幂等同键同载荷先回放旧收据，不重复 writer；不同最终载荷或范围拒绝。

## 迁移与便携

M09 仅由中央 lane 在事务中安装。范围计数器和两个 scope 列是新增数据；三张反馈表在 FK 开启时重建。v1 新列保持 NULL，读取时推导字段 scope，不回写旧 source JSON、任务、nonce 或采用 hash。迁移失败须回滚旧表、行、索引、FK 和版本。

源 schema 9 的守恒投影保留全部 M08 旧列，只排除 M09 新表与两列。更早源版本的专用投影排除其后引入的数据；缺失或篡改投影仍阻止物理切换。

便携读取分别核定 7/8/9/10 的表/字段集合。范围 source/scope/adopted scope 使用闭集解析，v1 NULL 编码保持兼容。新副本只获得可读、不可重放的旧候选及收据；重新采用必须显式捕获当前底稿并建立新 lineage。保留既有两阶段 nonce 历史标签转换，禁止恢复旧执行权或混合来源摘要。

## 验收与回退

验收包括真实 F0→C1→C2 与部分章采用、范围外 raw bytes、非法载荷零写入、ABA/同内容/重试/事务失败、关库重开、FK 父链/采用历史迁移及各阶段注错回滚，以及旧包恢复、显式新 lineage 和二次归档。历史兼容分开记录两种证据：固定 Stage 2A 源码闭包独立构造旧 schema 9 指纹；依据旧协议字面编码重建的持久证明经迁移、重开后仍可读及幂等回放。后者不是实际运行旧 producer 的证据。

停用新范围入口不删除旧候选、采用历史或作者正文；不自动降级 schema。本决定及静态 review 不证明文学质量、可见设计或目标平台资格。
